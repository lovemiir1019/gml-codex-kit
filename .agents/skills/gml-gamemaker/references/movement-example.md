# 素材なしの移動例

対象: 現代のGameMaker / GML Code。既存ゲームから独立した確認用。
状態: ソースを点検した例。GameMakerでのビルド・実行は未確認。

1. GameMakerで空のGML Codeプロジェクトを用意する。
2. `obj_player` というオブジェクトを作る。スプライトの指定は不要。
3. Create、Step、Drawの3イベントを追加する。
4. [Create](../assets/top-down-player/Create_0.gml)、[Step](../assets/top-down-player/Step_0.gml)、[Draw](../assets/top-down-player/Draw_0.gml)の内容を、対応する新規イベントにそれぞれ貼る。ファイルそのものをプロジェクトへ置くだけでは登録されない。
5. `obj_player` をルームのインスタンスレイヤーに1体配置する。最初の位置は `(160, 120)`、ルームは `640 × 480` など、幅・高さとも24より大きくする。
6. この例では物理を使わず、ルーム全体が見える状態で起動する。

確認する操作と期待結果:

| 操作 | 期待する結果 |
| --- | --- |
| 何も押さない | 円が勝手に移動しない |
| 矢印キーを押す | その方向へ移動する |
| 斜めに押す | まっすぐ進むときと移動速度が同じ |
| 左右を同時に押す | 横方向には進まない |
| ルーム端へ進む | 円全体がルーム内に収まる |

カメラ追従、壁との衝突、ジャンプ、物理移動はこの例に含まれない。
既存のゲームへ入れる場合は、そのゲームの処理に合わせて組み込む。
