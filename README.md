# GMLアシスタントキット

**日本語で作りたい動きを伝えると、GameMaker用のGMLコードと、その入れ方を受け取れます。**

「矢印キーで動かして」「敵に当たったらHPを減らして」「このエラーを直して」のように頼めます。
Codexでファイルを編集する方法と、普通のChatでコードを受け取る方法の両方に対応する、指示文・スキル・手順書のセットです。
独立したAIサービスや、GameMakerへ自動接続する実行プログラムではありません。
スキルとは、Codexに渡す作業ルールのことです。GameMakerの用語で迷ったら [用語集](docs/GLOSSARY.md)を参照してください。

## まずは、使う場所を選んでください

| 使い方 | やること | 向いている場面 |
| --- | --- | --- |
| [普通のChatで使う](docs/CHAT.md) | [指示文](chat/START_HERE.md)を全文貼り、その後に日本語で頼む | すぐ試したい、Codexの上限に達した |
| [Codexで使う](docs/CODEX.md) | ゲームのフォルダへスキルを置き、日本語で頼む | 既存ファイルを読みながら修正したい |
| [作業を引き継ぐ](docs/HANDOFF.md) | 現状のメモとコードを次のChatやCodexへ渡す | 利用上限や会話の切り替えに備えたい |

初めての人は、上のどちらか一つの手順だけで始められます。

## たとえば、こう頼めます

> 見下ろし型のゲームです。矢印キーでプレイヤーを動かして、斜めだけ速くならないようにしてください。ルームの外にも出ないようにしたいです。画像はまだありません。

返答には、必要な準備、オブジェクトとイベント別のGML、貼り付け方、試し方を含めます。
すでにゲームがある場合は、関連する現在のコードも渡してください。毎回ゼロから作り直す前提にはしません。

## お金のかかる外部サービスは組み込みません

このキットはMITライセンスで、利用・改変・再配布できます。APIキー、ホスティング、独自サーバー、有料プラグインは不要です。
普通のChatでは、利用者の使える無料枠の範囲で利用します。Codexは利用者の契約・利用枠で動きます。
Chatにも利用上限があるため、切り替え先が必ず使えるとは保証しません。上限を回避する仕組みではありません。

2026年10月16日に確認した[Codex公式の料金案内](https://learn.chatgpt.com/docs/pricing)では、Freeプランにも段階的に提供されるデスクトップ向けの利用枠があります。利用できる機能や上限はアカウントによって確認してください。
このキットが追加課金やクレジット購入を自動で行うことはありません。GameMaker本体の利用・ゲーム配布条件はGameMakerの条件に従います。

## 既存ツールを活用します

GMLやGameMakerの支援ツールはすでに存在します。本キットではGMLのパーサーやビルド機能を作り直さず、必要なら[公式gm-cli](https://github.com/YoYoGames/gm-cli)などにつなぐ方針です。
基本のChat版とCodexスキルは、それらを追加導入しなくても使えます。

調べた候補と役割は [既存ツールの調査](docs/EXISTING_TOOLS.md)にまとめています。第三者ツールのコードや公式マニュアル本文は、このリポジトリに転載していません。

## GML用のルールを共有します

Codex版とChat版は [同じGML共通ルール](.agents/skills/gml-gamemaker/references/gml-rules.md)を使います。
GMLとJavaScriptの違い、イベント、変数の寿命、インスタンス、資源解放、版の違い、読みやすいコードの書き方を扱います。
Chat用の指示文は共通ルールから生成し、片方だけ古くなるのを防ぎます。

ルールはAIへの指示です。モデルの回答やコードの正しさを強制・保証する実行機能ではありません。生成後はGameMakerで確認してください。
