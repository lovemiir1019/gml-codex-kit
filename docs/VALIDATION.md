# 初版で確認した範囲

検証日: 2026年10月16日 / 対象: 0.1.0

## 構造と共通ルールの整合性

| 確認 | 結果 |
| --- | --- |
| スキルの公式検証スクリプト | 合格。名前とフロントマター等を検査 |
| 文字コードと日本語 | UTF-8として読み込み可能。文字の置換記号なし |
| Markdownのローカルリンク | 参照先ファイルの存在を確認 |
| Chat生成用Pythonの構文 | 構文解析に合格 |
| 共通ルールと配布用Chat指示文 | `--check` で一致 |
| 共通ルールだけを変更した場合 | 隔離したコピーで、不一致を終了コード1で検出 |
| 不一致の後に再生成した場合 | 一致に戻ることを確認 |

通常の利用にPythonやPyYAMLの導入は不要です。これらは作成・検査時の道具です。
日本語の静的検査はuv環境がなかったため、natural-japaneseの手動チェックリストで代替しました。自動の文章スコアは出していません。

## 説明書と相談例のレビュー

構造、読みやすさ、ガイドとしての操作手順とGMLの扱いを、別々のレビューで点検しました。
確認した相談例は、画像なしの矢印移動、既存イベントの一部で起きた未初期化変数のエラー、CodexとChatの切り替えです。
これは指示文とサンプルを読み、想定する返答を検討したレビューです。実際の利用者環境での反復評価や、モデルごとの成功率測定ではありません。

レビューを受け、次の点を修正しました。

- スキルのコピー先フォルダを作る手順と、GameMakerの保存・再読み込みの順序
- Chatからコードを貼り付ける具体的な操作と、部分修正を希望した場合の扱い
- 用語集と、引き継ぎメモの保存方法
- Draw追加時に標準のスプライト表示が置き換わる点

## GameMakerでの動作は未確認

この作業環境では、同梱のGMLをGameMakerでビルド・起動・操作していません。
移動サンプルはイベント間の変数、斜め入力の正規化、ゼロ除算の回避、ルーム境界、描画色の復元をソース上で点検しています。
実際に試す操作と期待結果は [移動例の手順](../.agents/skills/gml-gamemaker/references/movement-example.md)に記載しています。

公式gm-cliや第三者のMCPも、今回の環境へは導入・接続していません。
Codexスキルの読み込み、モデルからの返答、生成したGMLの動作は、利用するCodex・Chat・GameMakerの環境で確認が必要です。

問題があれば、再現条件と対象版を添えてIssuesへ報告してください。修正した機能の確認から順に実績を残します。
