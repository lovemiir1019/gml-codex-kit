# GameMakerとこのキットの用語

| 用語 | このキットでの意味 |
| --- | --- |
| GML | GameMakerで動きを書くためのプログラミング言語 |
| オブジェクト | プレイヤーや敵などの、動きと見た目をまとめる設計図 |
| インスタンス | オブジェクトから作られ、ルーム内に存在する一体。敵が3体いれば3インスタンス |
| イベント | 処理を実行するタイミングや条件。Create、Step、Drawなど |
| Create | そのインスタンスが作られたときに行う処理。初期値などを書く |
| Step | ゲームの更新ごとに行う処理。入力や移動などを書く |
| Draw | 描画するときの処理。通常のDrawへ自分で処理を追加すると、標準の画像描画が置き換わる |
| ルーム | キャラクターなどを配置する、ゲームの場面 |
| スプライト | キャラクターなどに使う画像やアニメーション |
| IDE | GameMakerの編集画面を含む開発ソフト。IDEの版はそのソフトのバージョン |
| Runtime | 作ったゲームを動かすための仕組み。IDEと別に版がある |
| .yyp / .yy / .gml | プロジェクト構成 / 個々の資産の定義 / GMLのコードを持つファイル |
| スキル / SKILL.md | Codexに渡す作業ルール / そのルールを記すファイル |
| .agents/skills | ゲームのフォルダ内に置く、Codex用スキルの保存場所 |
| ビルド | ソースコードから実行できるゲームを作る処理 |
| CLI | 文字の命令で操作するツール。基本のChat版では使わない |
| MCP | AIクライアントと外部ツールをつなぐ共通の仕組み。このキットの基本機能には不要 |
| 資源解放 | 自分で確保したデータや描画用メモリーなどを、不要になったときに片付ける処理 |
| MITライセンス | 利用・改変・再配布を認める条件。著作権表示などの条件はLICENSEに記載 |
