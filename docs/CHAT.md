# 普通のChatで日本語からGMLを作る

専用のGPT作成やプラグイン導入は不要です。通常のChatGPTで、利用できる無料枠の範囲で使います。
Chatはコードを返し、GameMakerへ貼り付けて動かす作業は自分で行います。

## 指示文を最初に貼る

1. [START_HERE.md](../chat/START_HERE.md)を開き、本文を最初から最後までコピーする。GitHubならRaw表示を使うとコピーしやすくなります。
2. 通常のChatGPTで新しい会話を開き、全文を送る。
3. 続けて、作りたい動きを日本語で送る。

最初の依頼例:

```text
見下ろし型のゲームを作っています。
矢印キーでキャラを動かし、斜めだけ速くならないようにしたいです。
ルームの外にも出ないようにしてください。まだ画像はありません。
どのオブジェクトの、どのイベントに貼るかも教えてください。
```

GameMakerの版がわかれば一緒に伝えます。不明なら不明と書いて構いません。

## 既存のゲームを修正する

関係するイベントの現在のコードと、初期値を設定しているCreateなどのコードを添えます。
次のように、残したい動きも伝えると変更範囲が明確になります。

```text
次は obj_player の Step 全文です。
ジャンプと壁の当たり判定はそのままで、移動速度だけ調整しやすくしてください。
この後にCreateのコードも貼ります。両方を見てから修正してください。
```

コードを受け取ったら、GameMakerで指定されたオブジェクトを開き、指定イベントのコード画面を開きます。
「新規」はイベントを作って貼る、「追記」は今のコードを残して指定位置に足す、「置換」は指定された部分を入れ替える、という意味です。
指示どおりに貼り、保存してゲームを実行します。新規オブジェクトの場合は、必要に応じてルームへ配置する手順も行います。
全文を送っていないイベントを、短い修正案だけで丸ごと置き換えないでください。

## エラーが出たら、そのまま相談する

```text
この修正を適用したら、右キーを押したときに次のエラーが出ました。
期待する動き: 右へ移動する
実際の動き: ゲームが止まる
対象: obj_player / Step
エラー全文: （ここに貼る）
現在のStep全文: （ここに貼る）
関連するCreateのコード: （ここに貼る）
```

エラーを自分の言葉だけに省略せず、行番号を含めて渡すと原因を絞りやすくなります。
直った場合は、どのコードを適用して何を試したかも返します。

## 会話を切り替えるとき

「引き継ぎメモを作って」と頼み、返ってきたメモをコピーします。メモ帳などで、ゲームのフォルダに `GML_HANDOFF.md` という名前で保存します。
新しい会話では、指示文、引き継ぎメモ、現在の関連コードを渡します。
Chatの返答はゲームのファイルへ自動保存されません。未適用の提案を適用済みとして引き継がないようにします。

Chat側にも利用上限があります。[引き継ぎ手順](HANDOFF.md)を使えば、次に利用できるときに続きを説明し直す負担を減らせます。
GameMakerの用語は [用語集](GLOSSARY.md)で確認できます。
