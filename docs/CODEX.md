# Codexで日本語からGMLを作る

ゲームのファイルをCodexで開き、作成や修正を頼むための手順です。
最初は「スキルを置く」「日本語で頼む」の2つを行います。ツール連携の追加設定は、必要になってからで構いません。

## ゲームのフォルダにスキルを置く

1. GitHubで「Code → Download ZIP」を選び、ダウンロードしたZIPを展開する。
2. GameMakerで開くプロジェクトファイル（名前の末尾が `.yyp`）のあるフォルダを探す。その中に `.agents`、その中に `skills` というフォルダを作る。すでにあれば、そのまま使う。
3. 展開したキットの `.agents/skills/` にある `gml-gamemaker` フォルダを、作った `skills` の中へ丸ごとコピーする。
4. Codexで、ゲームの `.yyp` があるフォルダを開く。

完成形は次のようになります。`MyGame` は自分のゲームの名前に読み替えてください。

```text
MyGame/
  MyGame.yyp
  objects/
  scripts/
  .agents/
    skills/
      gml-gamemaker/
        SKILL.md
        agents/
        references/
        assets/
```

すでに `.agents` フォルダがある場合は、中身を消さず、`gml-gamemaker` だけを追加します。
同じ名前のスキルがすでにある場合は、既存の内容を確認してから更新してください。
導入後に認識されない場合は、Codexを開き直します。

[公式のスキル説明](https://learn.chatgpt.com/docs/build-skills)では、プロジェクト内の `.agents/skills` が読み込み先として案内されています。

## 日本語で頼む

最初の依頼例:

```text
$gml-gamemaker を使ってください。
まずこのGameMakerプロジェクトの構成を確認してください。
プレイヤーの移動速度を調整しやすくしたいです。
今の当たり判定とジャンプは保って、読みやすいGMLにしてください。
変更した場所と試し方も日本語で教えてください。
```

以降は「敵に当たったときに3秒間だけ無敵にして」「このエラーを直して」のように頼めます。
Codexが対象の版を確認できない場合や、ゲームが複数ある場合は、必要な情報を答えてください。

## GameMakerで試す

Codexがファイルを変更しても、GameMaker上の操作結果まで自動で確認できるとは限りません。
実行未確認と報告された場合はGameMakerで起動し、案内された操作を試します。
Codexへ修正を頼む前に、GameMakerで編集中の内容を保存します。
Codexの変更後は、GameMakerの外部更新通知に従うか、プロジェクトを開き直して変更を読み込みます。古い編集内容をそのまま保存すると、Codexの修正を消すおそれがあります。
新しいイベントやオブジェクトを手動で追加するよう案内された場合は、その準備を済ませ、コードを保存してから実行します。

## 公式ツールとの連携は後から追加できます

[公式gm-cli](https://github.com/YoYoGames/gm-cli)にはプロジェクト編集、ビルド、実行、AI用のResourceTool連携があります。
本キットはgm-cliを自動導入しません。利用する場合はNode.js、対象のRuntime、出力先などを確認し、公式の手順に従います。
ビルド環境がなくても、既存のGMLを読む・修正する作業やChatへの引き継ぎは行えます。

## 上限に備えてメモを残す

まとまった作業が終わったら、次のように頼みます。

```text
ここまでの作業を GML_HANDOFF.md に残してください。
適用済みと未適用、実行済みと未確認を分け、次のChatに渡すコードも教えてください。
```

切り替えの手順は [作業の引き継ぎ](HANDOFF.md)を参照してください。
GameMakerの用語は [用語集](GLOSSARY.md)で確認できます。
