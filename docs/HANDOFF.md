# CodexとChatの間で作業を引き継ぐ

上限に達する前に、一区切りごとにメモとコードを保存しておくと切り替えやすくなります。
すでに返答できない状態なら、保存済みのコードと直近のエラーから自分でメモを埋めても構いません。

## 渡すものは3つです

1. [Chat用の指示文](../chat/START_HERE.md)
2. [テンプレート](../.agents/skills/gml-gamemaker/assets/HANDOFF_TEMPLATE.md)を埋めた `GML_HANDOFF.md`
3. 変更対象イベントの現在のコード、関連する初期化コード、エラー全文

メモには、作りたいもの、環境、適用済みの変更、未適用の案、確認結果、次の一手を残します。
「修正案が届いた」と「自分のゲームへ保存して動いた」は別の状態です。
Codexでメモを保存した場合は、そのファイルを使います。Chatが返したメモは自動保存されないため、本文をコピーし、メモ帳などでゲームのフォルダへ `GML_HANDOFF.md` として保存します。

## CodexからChatへ

Codexでメモを作り、必要なコードと一緒にChatへ送ります。
最初の一言は「このメモの続きです。コードを確認して、次の一手から進めてください」で十分です。
添付やファイル読み込みが使えないChatでは、必要な部分を本文に貼ります。

## ChatからCodexへ

Chatの修正をGameMakerのファイルへ保存し、試した結果をメモに追記します。
まだ適用していない案は、そう明記します。Codexでゲームのフォルダを開き、次のように頼みます。

```text
$gml-gamemaker を使って、GML_HANDOFF.md と現在のコードを確認してください。
メモとファイルが違う場合は、どこが違うか確認してから続きを進めてください。
```

ゲーム全体のバックアップやGitの変更履歴も残しておくと、戻す場所がわかります。
引き継ぎメモはバックアップやソースコードの代わりにはなりません。
